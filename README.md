## 🟢 Dosyalarını Türlerine Göre Otomatik Düzenle

[ ⚠️ ] [Hata Alıyorsan Buraya Tıkla!](#-hata-alıyorsan)

**Karmaşık klasörlerinizi saniyeler içinde düzenleyen, kurulumu kolay Python scripti.**

<p align="center">
  <a href="https://git.io/typing-svg">
    <img src="https://readme-typing-svg.herokuapp.com?font=Delicious+Handrawn&size=30&pause=1000&color=00D4FF&repeat=false&width=435&lines=%E2%9C%93+Kurulum" alt="Typing SVG" />
  </a>
</p>

- İlk olarak bilgisayarına [Python](https://www.python.org/downloads/) `(en düşük v3.8)` indir.

- Daha sonra projeyi indirip bir klasöre çıkart.

- Ek bir modül gerekmez, direkt kullanmaya başlayabilirsin.

- Önce dosyalara dokunmadan ne olacağını görmek için terminale aşağıdaki kodu yaz.

```
python organizer.py "C:\Users\Kullanici\Downloads" --deneme
```

- Sonuçtan memnunsan `--deneme` kısmını silip tekrar çalıştır!
- Bu kadar, dosyaların düzenlendi.
- Aynı isimde dosya varsa üzerine yazmaz, sonuna `(1)`, `(2)` ekler.
- Örnek kullanım: `python organizer.py ~/Downloads`

### 📁 Kategoriler

| Klasör | Uzantılar |
| --- | --- |
| Resimler | `.jpg` `.png` `.gif` `.webp` `.svg` |
| Videolar | `.mp4` `.mkv` `.avi` `.mov` |
| Muzikler | `.mp3` `.wav` `.flac` |
| Belgeler | `.pdf` `.docx` `.txt` `.xlsx` `.pptx` |
| Arsivler | `.zip` `.rar` `.7z` |
| Kodlar | `.py` `.java` `.cpp` `.js` `.html` |
| Programlar | `.exe` `.msi` `.apk` |
| Diger | Yukarıdakilere uymayan her şey |

Kategorileri değiştirmek için `organizer.py` içindeki `KATEGORILER` bölümünü düzenleyebilirsin.

# ⚠️ Hata Alıyorsan

## `python` komutu tanınmıyorsa

Python'u kurarken **"Add Python to PATH"** kutucuğunu işaretlemeyi unutmuş olabilirsin. Python'u yeniden kurup bu kutucuğu işaretle, ardından terminali kapatıp aç.

Olmazsa `python` yerine `py` veya `python3` yazmayı dene.
